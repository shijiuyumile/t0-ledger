# 做T台账

A 股散户做 T+0 的「买入成本台账」手机应用（PWA），核心能力：

- **买入成本台账**：按标的分组展示每只票的待做T买单（各笔买入价、剩余数量、佣金/过户费/印花税明细），每笔可填预估卖价实时试算净利润（已扣双边费用）。
- **价格最相近核销**：每笔卖单不按时间配对，而是优先配"低于卖价且价格最高"的剩余买单；没有更低的就配高于卖价里最接近的；数量不等自动级联到次接近的买单。
- **做T战绩**：整笔卖单扣除双边费用后净赚记为"做T成功"（默认隐藏），净亏保留在"亏损卖出"筛选里；战绩页统计累计净利、成功率、按日/按标的明细。
- **交割单导入**：从券商导出的 Excel 交割单/对账单增量导入，自动识别表头、自动去重（凭成交编号或日期+时间+代码+方向+价格+数量），非成交行（分红、利息等）自动忽略；也支持手动录入。
- **费率规则**（可在"我的"页修改）：
  - 股票：佣金万 0.85（最低 5 元）+ 过户费万 0.1（双向）+ 印花税万 5（仅卖出）
  - ETF：佣金万 0.5（最低 0.1 元），免过户、免印花
  - 债券：佣金万 0.1
  - 交割单里带实际费用时优先用实际值；手动录入按上述规则自动计算。
- 亮色界面、红涨绿跌（红=盈利，绿=亏损）、iPhone 全面屏适配、离线可用。

## 如何在 iPhone 上使用（无需上架 App Store）

这是一个 PWA 网页应用，只要放到一个 HTTPS 网址上，用 Safari"添加到主屏幕"即可像原生 APP 一样使用。**所有数据只存在你手机本地，不会上传到任何服务器。**

### 方式一：Netlify 拖拽部署（最简单，5 分钟）

1. 打开 <https://app.netlify.com/drop>（需注册一个免费账号，可用邮箱注册）。
2. 把整个 `t0-ledger` 文件夹拖进网页上传。
3. 上传完成后会得到一个 `https://xxxx.netlify.app` 网址。
4. 用 iPhone 的 **Safari** 打开这个网址 → 点底部**分享按钮** → **添加到主屏幕**。
5. 主屏幕上会出现红色 "T" 图标，点开就是全屏 APP，之后离线也能用。

### 方式二：GitHub Pages（免费、长期稳定）

1. 注册 [GitHub](https://github.com) 账号，新建一个仓库（比如 `t0-ledger`）。
2. 把本文件夹里的所有文件上传到仓库（网页端 "Add file → Upload files" 即可）。
3. 仓库 Settings → Pages → Source 选 `main` 分支根目录，保存。
4. 几分钟后访问 `https://你的用户名.github.io/t0-ledger/`，然后同上"添加到主屏幕"。

### 重要提醒

- 数据存在 Safari 的本地存储里。**请定期在"我的 → 数据备份"里导出 JSON 备份**（换手机、清理 Safari 数据前必须备份）。
- 如果长期（约 7 天以上）不打开该 APP，iOS 可能清理网站数据，勤备份可保无忧。
- 交割单文件先通过微信/隔空投送等传到 iPhone 的"文件"APP，再在导入页选择即可。

## 电脑上本地预览

```bash
node tools/serve.js 8765
# 浏览器打开 http://localhost:8765
```

## 目录结构

```
index.html          页面骨架
css/style.css       样式（亮色、红涨绿跌）
js/fees.js          费率计算
js/match.js         价格最相近核销算法 + 预估利润
js/store.js         本地存储、去重、备份
js/import.js        Excel 交割单解析与字段映射
js/app.js           界面渲染与交互
vendor/xlsx.full.min.js  SheetJS（Excel 解析库，本地化保证离线可用）
manifest.json / sw.js    PWA 配置与离线缓存
tools/              开发辅助：图标生成、算法自测、样例交割单、本地服务器
```

## 修改代码后注意

改动任何 js/css/html 后，把 `sw.js` 里的 `CACHE_VERSION` 版本号 +1（如 `t0ledger-v2`），否则已安装的手机端可能继续用旧缓存。
